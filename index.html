Overview

About the Project

🎯

Objective

Predict whether an individual is at Low or High health risk using key vital parameters and lifestyle data.

📊

Dataset

Trained on anonymised clinical health records with age, BMI, blood pressure, glucose, and lifestyle indicators.

🤖

Model

Uses a supervised classification algorithm (Random Forest / Logistic Regression) for accurate predictions.

✅

Accuracy

Achieves ~94% accuracy on the test set, validated with cross-validation and confusion-matrix analysis.

Pipeline

How It Works

A simple three-step pipeline from input to prediction.

Input Data

2
